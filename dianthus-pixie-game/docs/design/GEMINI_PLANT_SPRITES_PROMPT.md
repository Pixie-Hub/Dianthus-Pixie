# Gemini Image Generation Prompt — Dianthus Pixie Plant Sprites

## Global Style Rules

```
All plant sprites share these rules:
- Strict pixel art — no anti-aliasing, no gradients, no soft edges, no sub-pixel rendering
- Exactly 32x32 pixels per sprite
- Transparent background — no solid background color
- Limited palette: ~6-10 colors per plant
- Clean readable silhouette at 32x32 scale
- 1-pixel dark outline around the plant body
- Top-down / slightly angled top-down perspective (~30 degrees)
- Output: single PNG, 32x32 pixels, transparent background, no upscaling, no smoothing
- Art direction: 2D pixel art, fantasy survival crafting, Southeast Asian botanical theme
- Plants occupy roughly 28-30 pixels of canvas, leaving 1-2px padding
```

## Usage Notes

- Import each sprite into Godot as `Texture2D` with **Filter = Nearest**.
- Store at `assets/sprites/plants/<plant_name>.png`.
- Replace the current placeholder `icon.svg` + `scale = Vector2(0.15, 0.15)` in each `.tscn`.
- Each plant occupies one 32x32 tile in the garden grid.
