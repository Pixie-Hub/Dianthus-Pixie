# Gemini Image Generation Prompt — Dianthus Pixie Resource Icons

## Global Style Rules

```
All icons share these rules:
- Strict pixel art — no anti-aliasing, no gradients, no soft edges
- Exactly 16x16 pixels per icon
- Transparent (checkerboard) background — no solid background color
- Limited palette: approximately 6–10 colors per icon
- Clean, readable silhouette — each icon must be recognizable at 16x16 scale
- No outline style (internal shading only) OR a 1-pixel dark outline — pick whichever reads clearest
- Output: a single PNG image per icon, 16×16 pixels, transparent background, no upscaling, no smoothing
- Art direction: 2D pixel art for a fantasy survival crafting game with a Southeast Asian botanical theme
```

## Usage Notes

- Import each icon into Godot as `Texture2D`.
- In the Godot import settings set **Filter** to `Nearest` (no interpolation) so icons stay crisp.
- Store icons in `assets/aseprite/icons/` (e.g. `assets/sprites/icons/petal_shard.png`).
- Icons will be used in the inventory grid (40x40 slot containers, icon displayed at 2x or 3x nearest-neighbor scale) and crafting/breeding UI screens.
